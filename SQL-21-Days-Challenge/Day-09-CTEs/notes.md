## Key takeaways
1. A CTE is defined with `WITH` and referenced by the main query.
2. A CTE exists only for the duration of its SQL statement.
3. Multiple CTEs are separated by commas after one `WITH`.
4. `WHERE` filters rows before grouping; `HAVING` filters grouped results.
5. A CTE can be joined to a base table using a common column.
