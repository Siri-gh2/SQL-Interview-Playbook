## Key takeaways
1. `DATEDIFF(a, b)` returns the number of days from `b` to `a`.
2. Use `DATE_ADD()` and `DATE_SUB()` with an `INTERVAL`.
3. `MONTH()` returns a numeric month; `MONTHNAME()` returns its name.
4. `DATE_FORMAT()` controls how a date is displayed.
5. `CURDATE()` makes calculations relative to the date the query runs.
