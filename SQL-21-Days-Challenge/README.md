## How to run Day 01

1. Open MySQL Workbench and connect to your MySQL server.
2. Open `Day-01-WHERE/schema.sql` and execute it to create the practice database and sample table.
3. Open `Day-01-WHERE/solution.sql` and execute the questions individually or all together.
4. Compare the returned rows with the expected outputs documented in `notes.md`.

All exercises in this repository are practice exercises created during the challenge. The roadmap topics are based on the uploaded 21-day challenge spreadsheet.
