## Common mistakes
- MySQL `SUBSTRING()` positions start at 1, not 0.
- `LENGTH()` counts bytes; `CHAR_LENGTH()` counts characters.
- `TRIM()` removes leading/trailing spaces, not internal spaces.
- `LEFT()` and `RIGHT()` take the string first and count second.
- MySQL `CONCAT()` returns NULL if any argument is NULL.
